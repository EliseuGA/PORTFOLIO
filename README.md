# CADEIRANTE MAROMBA — Portfólio

> Portfólio pessoal desenvolvido para apresentar meus trabalhos como **Desenvolvedor de Sistemas, Editor de Vídeo e Motion Designer**.

Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido com **HTML, CSS e JavaScript**, com foco em apresentar meus projetos de edição audiovisual e, ao mesmo tempo, aplicar conceitos de desenvolvimento web, organização de arquivos, responsividade e experiência do usuário.

**Portfólio:** [cadeirantemaromba.vercel.app](https://cadeirantemaromba.vercel.app/)

---

## Sobre o projeto

Este projeto nasceu da união entre duas áreas que fazem parte da minha formação e dos meus objetivos profissionais: **tecnologia e produção audiovisual**.

O objetivo é criar uma experiência que não funcione apenas como uma página com trabalhos, mas como uma interface capaz de apresentar cada projeto de maneira organizada e visualmente coerente.

A identidade do site foi construída em torno do conceito de um **arquivo digital**, utilizando elementos inspirados em sistemas antigos, acervos, documentos e interfaces de computadores.

Dessa forma, o próprio portfólio se torna parte do trabalho apresentado.

## Processo de desenvolvimento

O desenvolvimento do portfólio foi realizado pensando tanto na **funcionalidade quanto na identidade visual**.

Assim como em uma edição de vídeo, cada elemento da interface possui uma função dentro da experiência:

**estrutura → interação → ritmo → apresentação**

No desenvolvimento web, isso se traduz em:

```text
HTML
  ↓
Estrutura

CSS
  ↓
Identidade + Layout + Animação

JavaScript
  ↓
Interação + Lógica

Deploy
  ↓
Experiência final
```

A mesma lógica utilizada na edição audiovisual — organizar informação, controlar ritmo e direcionar a atenção do espectador — também foi aplicada na construção da interface.
